# Бот-бекенд · Історія України · Тренажер НМТ

Маленький Node.js-сервер, який дає боту "справжній бекенд": обробляє натискання
`/start`, `/premium`, приймає оплату Telegram Stars, зберігає, хто вже преміум,
і вміє розсилати повідомлення всім користувачам (нагадування, стрік тощо).

База даних — [Turso](https://turso.tech) (SQLite у хмарі): безкоштовно, без
обмеження в 30 днів (на відміну від безкоштовного Postgres у Render) і без
власного диска — тому сам застосунок на Render може спокійно бути на
безкоштовному тарифі й "засинати", дані від цього не постраждають.

## Крок 1. Створити базу даних у Turso (безкоштовно)

1. Зареєструйся на [turso.tech](https://turso.tech) (можна через GitHub).
2. Онови/встанови Turso CLI, або просто через веб-інтерфейс (Dashboard →
   Create Database). Назви базу, наприклад, `nmt-history-bot`.
3. У Dashboard бази з'явиться:
   - **Database URL** — виглядає як `libsql://nmt-history-bot-<акаунт>.turso.io`
   - Кнопка **Create Token** → згенеруй токен (auth token)
4. Збережи обидва значення — знадобляться на кроці 3.

## Крок 2. Запушити цей код у GitHub

Ця папка (`bot-backend`) — окремий підпроєкт у тому ж репозиторії
`history-of-Ukraine`, поруч із `ukraine-history-quiz`. Просто закомить і
запуш її через GitHub Desktop, як завжди.

## Крок 3. Створити новий Web Service на Render

1. У Render Dashboard → **New** → **Web Service**.
2. Підключи той самий репозиторій `history-of-Ukraine`.
3. **Root Directory**: `bot-backend` (важливо — інакше Render шукатиме
   package.json не там).
4. **Build Command**: `npm install`
5. **Start Command**: `npm start`
6. Тариф — спочатку можна залишити **Free** (поки тестуємо; коли з'являться
   реальні платні користувачі, апгрейднемо на Starter, щоб не засинав).
7. У розділі **Environment** додай змінні (значення — зі свого `.env`,
   дивись `.env.example` у цій папці за списком):
   - `BOT_TOKEN` — токен бота від @BotFather
   - `WEBHOOK_SECRET` — будь-який випадковий рядок (придумай сам, наприклад
     32 випадкових символи)
   - `ADMIN_SECRET` — інший випадковий рядок (для розсилок)
   - `TURSO_DATABASE_URL` — з кроку 1
   - `TURSO_AUTH_TOKEN` — з кроку 1
   - `FRONTEND_ORIGIN` — `https://grekis5552.github.io`
   - `PREMIUM_PRICE_STARS` — `300` (або інша ціна)
8. Натисни **Create Web Service** — Render задеплоїть і дасть тобі адресу
   типу `https://nmt-history-bot.onrender.com`.

## Крок 4. Прив'язати вебхук бота до нового сервера

Після того як сервіс задеплоївся (в логах Render має з'явитись
`[server] Слухаю на порту ...`), зроби один запит у браузері (або через
curl), щоб Telegram почав надсилати повідомлення на цей сервер:

```
https://nmt-history-bot.onrender.com/admin/set-webhook
```

— але цей ендпоінт захищений, тож напряму в браузері не спрацює (поверне
403). Найпростіше виконати через термінал:

```bash
curl -H "X-Admin-Secret: ТВІЙ_ADMIN_SECRET" \
  https://nmt-history-bot.onrender.com/admin/set-webhook
```

Має повернутись `{"ok":true,"result":true,...}`. Перевірити, що вебхук
справді встановився:

```bash
curl -H "X-Admin-Secret: ТВІЙ_ADMIN_SECRET" \
  https://nmt-history-bot.onrender.com/admin/webhook-info
```

## Крок 5. Перевірити

Напиши своєму боту `/start`, потім `/premium` — має прийти інвойс на оплату
в Telegram Stars. Тестову оплату можна зробити зірками, які видає сам
Telegram у тестовому режимі (або реальними, якщо вже підключений production
бот — тоді знімуться справжні зірки, тому спершу варто перевірити на
тестовому боті, якщо він у тебе є).

## Розсилка (нагадування)

```bash
curl -X POST \
  -H "X-Admin-Secret: ТВІЙ_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"text": "Не забудь пройти сьогоднішній квіз! 🔥"}' \
  https://nmt-history-bot.onrender.com/admin/broadcast
```

Параметр `"sinceDays": 14` у тілі запиту — надіслати лише тим, хто був
активний за останні 14 днів (щоб не спамити всіх підряд назавжди).

Пізніше це можна автоматизувати через безкоштовний cron (наприклад,
GitHub Actions за розкладом, який раз на день робить цей самий запит) —
скажи, коли будеш готовий, і налаштую.

## Супер-адмін дашборд

Після деплою відкрий у браузері:

```
https://nmt-history-bot.onrender.com/admin/
```

Це окрема сторінка (не Telegram Mini App, а звичайний сайт-панель), яка попросить
ввести той самий `ADMIN_SECRET`, що і в environment variables. Після входу
показує:

- зведену статистику (усього користувачів, скільки зараз преміум, скільки
  зірок отримано всього і за останні 7 днів);
- таблицю всіх користувачів — юзернейм, статус (преміум/free), до якої дати
  преміум, скільки заплатив зірок, коли востаннє був активний;
- таблицю всіх платежів.

Секрет вводиться прямо на сторінці й ніде більше не зберігається (крім
сесії браузера, щоб не вводити щоразу) — окремого логіна/пароля не
створювали, це той самий `X-Admin-Secret`, що і для розсилок.

## Місце для майбутніх предметів (не лише історія)

Бекенд і база даних тут прив'язані до користувача, а не до предмета, тому
додавання нової дисципліни (наприклад, географії) не потребує змін тут —
досить на фронтенді (`ukraine-history-quiz`) додати новий файл із питаннями
за такою ж структурою, як `questions.js`, і показати екран вибору предмета.
Див. коментар `SUBJECTS` у `questions.js` фронтенду.

## Що ще не зроблено (наступні кроки)

- Фронтенд (`ukraine-history-quiz/app.js`) поки перевіряє преміум лише
  локально через `config.js` (`OWNER_TELEGRAM_IDS`). Щоб реально пускати
  преміум-контент лише оплаченим користувачам, треба навчити фронтенд
  запитувати `GET /api/status/<telegram_id>` у цього бекенду замість
  локальної перевірки — це наступний крок, коли бекенд буде задеплоєний і
  перевірений.
- Автоматична щоденна розсилка (зараз запускається вручну запитом вище).
