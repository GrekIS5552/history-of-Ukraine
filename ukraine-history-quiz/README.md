# Історія України · Тренажер НМТ (Telegram Mini App)

Telegram Web App для підготовки з історії України у форматі "квізлету":
14 тем від найдавніших цивілізацій до подій 2014–сьогодні, банк із 600
питань (по 40+ на тему), кожен квіз бере 10 випадкових питань з теми,
прогрес зберігається на пристрої користувача.

Головний екран зроблено у стилі "курсу": hero-картка теми, кнопка "Обрати тему",
картка швидкого продовження останньої теми та блок "Мій прогрес" з рейтингом,
відсотком пройденого курсу, кількістю тем і серією днів (streak).

## Що всередині

- `index.html` — сторінка застосунку
- `style.css` — стилі (автоматично підлаштовуються під тему Telegram, включно з темною темою)
- `app.js` — логіка: екрани "теми → квіз → результат", прогрес, обмеження доступу
- `questions.js` — банк питань (14 тем, 600 питань), тут же й редагуєш/додаєш контент
- `config.js` — твої налаштування (власник, безкоштовні теми, вимикач монетизації)

Це чистий HTML/CSS/JS без збірки — можна відкрити `index.html` просто в браузері,
щоб перевірити, як усе виглядає (Telegram-специфічні речі на кшталт теми оформлення
підхоплюються лише всередині Telegram, поза ним застосунок теж працює на дефолтних кольорах).

## Крок 1. Створити бота і Mini App

1. У Telegram напиши **@BotFather**.
2. `/newbot` → задай ім'я та юзернейм бота (закінчується на `bot`).
3. Збережи токен бота (знадобиться пізніше, якщо захочеш робити бекенд/оплати).
4. `/newapp` (або в меню бота → Bot Settings → Menu Button / Mini App) → прив'яжи Mini App
   до щойно створеного бота і вкажи URL, де хоститиметься застосунок (крок 2).
5. Опціонально: `/setmenubutton` — щоб кнопка відкриття застосунку була одразу в чаті бота.

## Крок 2. Захостити файли (потрібен HTTPS)

Telegram Mini App обов'язково має бути на HTTPS-адресі. Найпростіші безкоштовні варіанти:

**GitHub Pages** (найпростіше):
1. Створи репозиторій на GitHub, заливь усі файли з цієї папки в корінь.
2. Settings → Pages → Source: гілка `main`, папка `/root`.
3. Отримаєш адресу типу `https://<юзернейм>.github.io/<репозиторій>/` — саме її вкажи в @BotFather.

**Vercel / Netlify** (теж безкоштовно, drag-and-drop):
- Завантаж папку через їхній веб-інтерфейс — отримаєш готовий HTTPS-домен одразу.

## Крок 3. Дізнатись свій Telegram id і відкрити собі повний доступ

1. Напиши боту **@userinfobot** — він надішле твій числовий `id`.
2. Відкрий `config.js`, впиши цей id у `OWNER_TELEGRAM_IDS`, наприклад:
   ```js
   OWNER_TELEGRAM_IDS: [123456789],
   ```
3. Поки що `MONETIZATION_ENABLED: false` — тобто взагалі всі теми відкриті всім
   (щоб просто протестувати застосунок). Коли захочеш увімкнути обмеження для інших
   і залишити повний доступ тільки собі — постав `MONETIZATION_ENABLED: true`.
   Тоді для всіх, крім `OWNER_TELEGRAM_IDS`, будуть безкоштовні лише перші
   `FREE_TOPICS_COUNT` тем, а решта покажуть заглушку "🔒 Premium · Stars".

## Крок 4. Наповнення питаннями

У `questions.js` кожна тема — це об'єкт із масивом `questions`. Формат одного питання:

```js
{
  q: "Текст питання?",
  options: ["Варіант А", "Варіант Б", "Варіант В", "Варіант Г"],
  correct: 0, // індекс правильної відповіді (0 = перший варіант)
  explanation: "Коротке пояснення, чому саме ця відповідь правильна.",
}
```

Зараз у кожній темі рівно 10 питань — квіз бере всі 10 і перемішує їх.
Якщо додаси більше (наприклад 20–30 на тему), застосунок автоматично
братиме 10 випадкових щоразу — це і дасть ефект "квізлету" з різними
підбірками при повторному проходженні. Можеш або дописувати питання сам,
або попросити мене згенерувати ще партію по конкретних темах.

## Крок 5 (пізніше). Монетизація через Telegram Stars

Поточна версія — фронтенд без бекенду, прогрес живе лише в `localStorage`
браузера/Telegram-клієнта користувача. Для реальних оплат Stars знадобиться:

1. **Бекенд** (навіть простий, напр. на Node.js/Cloudflare Workers), який:
   - приймає запит "розблокувати", створює invoice через Bot API
     (`sendInvoice` з `currency: "XTR"` для Stars),
   - слухає `pre_checkout_query` і підтверджує оплату,
   - після успішної оплати позначає користувача як "преміум" у базі даних
     (тоді доступ керується не лише `localStorage`, а й серверною перевіркою).
2. Оновлений `config.js`/`app.js`, які звертаються до цього бекенду замість
   локальної заглушки `MONETIZATION_ENABLED`.

Коли будеш готовий — скажи, і я допоможу спроєктувати й написати цю частину
(бот, бекенд, збереження прогресу в хмарі замість лише локального пристрою).

## Відомі обмеження поточної версії (прототип)

- Прогрес зберігається **тільки на одному пристрої** (localStorage), не синхронізується
  між телефоном і комп'ютером.
- Немає бекенду й бази даних — усе працює на статичних файлах.
- Оплата Stars ще не підключена (лише підготовлена архітектура в `config.js`).
